1. CGPA CALCULATOR
------------------------------------------------------------
Description:
Calculates student CGPA using grades and credit hours.

Steps:
- Enter total number of courses
- Input grades for each subject
- Enter credit hours
- System calculates GPA/CGPA
- Shows final result

Concepts:
- Loops
- Arithmetic calculations

============================================================

2. LOGIN & REGISTRATION SYSTEM
------------------------------------------------------------
Description:
A simple user authentication system using file storage.

Steps:
- Choose Register or Login
- Register with username and password
- Save user data in file
- Login using saved credentials
- Show success or error message

Concepts:
- File Handling
- Strings
- Conditional Statements

============================================================

3. SUDOKU SOLVER
------------------------------------------------------------
Description:
Solves Sudoku puzzles using backtracking technique.

Steps:
- Enter Sudoku puzzle
- Check valid input
- Apply backtracking algorithm
- Display completed solution

Concepts:
- Recursion
- Backtracking
- 2D Arrays

============================================================

4. BANKING SYSTEM
------------------------------------------------------------
Description:
Handles customer accounts, transactions, and banking operations.

Steps:
- Create customer account
- Open bank account
- Deposit and withdraw money
- Transfer funds between accounts
- View transaction history and balance

Concepts:
- OOP (Classes & Objects)
- File Handling
- Account Management
